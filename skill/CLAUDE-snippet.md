## Experiment map

`Experiment map/` describes the lab as data (component and model notes); the experiment-map Obsidian plugin draws it. For questions about what feeds, drives or controls something, and for editing the map, use the `experiment-map` skill and its CLI, `node .obsidian/plugins/experiment-map/cli.js` (start with `check`). For why the plugin behaves as it does, bugs, feature requests and updates, use the `experiment-map-internals` skill. Edit only component notes, model notes and `Config.md`; never edit `map.yaml`, `Sync report.md`, channel pages, `.hardware/` or `layout.json` by hand. The files in `.obsidian/plugins/experiment-map/` and `.claude/skills/experiment-map*/` are a release of the plugin: never edit them; the plugin is changed in its repository, github.com/taw181/obsidian-experiment-map.
