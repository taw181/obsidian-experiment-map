## Experiment map

`Experiment map/` describes the lab as data (component and model notes); the experiment-map Obsidian plugin draws it. For questions about what feeds, drives or controls something, use the `experiment-map` skill and its CLI, `node .obsidian/plugins/experiment-map/cli.js` (start with `check`). Edit only component notes, model notes and `Config.md`; never edit `map.yaml`, `Sync report.md`, channel pages, `.hardware/` or `layout.json` by hand.
